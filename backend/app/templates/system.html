Systemeinstellungen

Gilt für alle Mandanten. Geheimnisse (Client-Secret, API-Key) werden verschlüsselt gespeichert und nie wieder angezeigt; Umgebungsvariablen haben Vorrang.

Microsoft Graph (SharePoint)

App-Registrierung in Microsoft Entra ID (Client-Credentials-Flow, ohne Benutzeranmeldung). Benötigte Anwendungsberechtigungen mit Administratorzustimmung: Sites.Selected (nur freigegebene Websites, empfohlen) oder Sites.ReadWrite.All; zum Durchsuchen aller Websites zusätzlich Sites.Read.All.

KI-Zugang (OpenAI-kompatibel)

Zum Auslesen von Bestellungen (Kreditor, Beträge, Daten, Konto). Jede Schnittstelle im Format /v1/chat/completions funktioniert, z. B. OpenAI, Azure OpenAI, Mistral oder ein selbst betriebener Server (Ollama, vLLM).

Datenschutz: Bestelldokumente (Text bzw. Seitenbilder) werden zum Auslesen an den hier eingetragenen KI-Dienst übertragen. Nur Dienste mit Auftragsverarbeitungsvertrag (AVV) bzw. selbst betriebene Modelle verwenden.

Lokale Ablage

Bestelldateien von Mandanten mit lokaler Ablage liegen unterhalb dieses Verzeichnisses (je Mandant ein Unterordner, Auswahl unter Mandant › Einstellungen). Einstellbar über die Umgebungsvariablen ABLAGE_VERZEICHNIS und ABLAGE_MAX_MB; das Verzeichnis gehört in die Datensicherung.
